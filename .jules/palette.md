## 2023-10-25 - Focus visibility for filter buttons
**Learning:** Some custom buttons in the filter sidebar were missing `focus-visible:outline-2 focus-visible:outline-primary focus-visible:outline-offset-2` classes for keyboard navigation visibility. Adding these ensures consistent keyboard a11y.
**Action:** Always add standard focus visible styling to interactive elements, especially custom buttons that don't inherit them by default.
