# SEO Strategy

| Metadata | |
|---|---|
| Last updated | 2026-06-18 |
| Site URL | https://gamedeals.com.br |
| Framework | Next.js 16 App Router |

## Overview

GameDeals SEO relies on server-rendered metadata, dynamic sitemap, ISR-revalidated home page, and structured data. No client-side rendering for content pages — all data fetched at build/request time.

## Metadata

### Root Layout (`src/app/layout.tsx`)

Global defaults applied to all pages unless overridden:

```ts
export const metadata: Metadata = {
  metadataBase: new URL('https://gamedeals.com.br'),
  title: {
    default: 'GameDeals — Best Game Deals & Price Tracking',
    template: '%s | GameDeals',
  },
  description: 'Find the best game prices across Steam, Epic, GOG...',
  openGraph: { ... },  // OG image, site name, locale
  twitter: { ... },     // Card type, site handle
  robots: { index: true, follow: true },
};
```

### Dynamic Metadata

Pages with dynamic content use `generateMetadata()`:

| Page | Metadata Source | Dynamic Fields |
|------|----------------|----------------|
| `/game/[id]` | `generateMetadata()` | Title (game name + price), description (deal summary), OG image (game thumb) |
| `/collections/[slug]` | `generateMetadata()` | Title (collection name), description |

### Static Metadata

These pages use `export const metadata`:

## Structured Data (JSON-LD)

### Root Layout

`WebSite` schema with `SearchAction` — enables sitelinks search box in Google.

```tsx
<script type="application/ld+json">
  {JSON.stringify({
    '@context': 'https://schema.org',
    '@type': 'WebSite',
    name: 'GameDeals',
    url: 'https://gamedeals.com.br',
    potentialAction: {
      '@type': 'SearchAction',
      target: 'https://gamedeals.com.br/search?q={search_term_string}',
      'query-input': 'required name=search_term_string',
    },
  })}
</script>
```

### Game Detail Pages

`Product` schema with `Offer` — enables rich results (price, availability) in Google.

```tsx
<script type="application/ld+json">
  {JSON.stringify({
    '@context': 'https://schema.org',
    '@type': 'Product',
    name: gameTitle,
    description: gameDescription,
    image: gameThumb,
    offers: {
      '@type': 'Offer',
      price: bestPrice,
      priceCurrency: 'USD',
      availability: 'https://schema.org/InStock',
    },
  })}
</script>
```

## Sitemap (`src/app/sitemap.ts`)

Dynamic sitemap generated at build/request time. Structure:

| Section | Entries | Priority | Change Freq |
|---------|---------|----------|-------------|
| Home | 1 | 1.0 | daily |
| Search, Bundles | 2 | 0.7–0.8 | weekly |
| Collections | 1 | 0.7 | monthly |
| Collection detail pages | 4 | 0.8 | daily |
| Game detail pages | up to 50k | 0.7 | weekly |

**DB fallback**: If the database is unavailable during build (e.g., CI without migrations), the sitemap returns only static pages — no crash.

**Submission**: Automatically discovered by Google via `robots.txt` → `sitemap.xml`. No manual submission needed.

## ISR (Incremental Static Regeneration)

| Page | Strategy | Revalidate |
|------|----------|------------|
| Home (`/`) | ISR | 3600s (1 hour) |
| Game detail (`/game/[id]`) | SSR (dynamic) | N/A |
| Search (`/search`) | SSR (dynamic) | N/A |

**Why ISR on home?** The deals list changes hourly (CheapShark cron every 4h). ISR balances freshness with cache efficiency — cached HTML served instantly, then revalidated in background.

## Canonical URLs

Set via `metadata.alternates.canonical` in root layout. No duplicate content issues — Next.js App Router enforces unique routes.

## robots.txt

Auto-generated by Next.js. Based on `metadata.robots` config. Current: `index: true, follow: true` for all pages.
