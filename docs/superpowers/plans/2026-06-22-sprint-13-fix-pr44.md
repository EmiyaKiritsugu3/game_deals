## Task 1: Fix E2E search result selector

**Files:**
- Modify: `tests/e2e/full-journey.spec.ts:44-50`

**Interfaces:**
- Consumes: SearchBox component (`src/components/navbar/SearchBox.tsx`) renders results in `div.${styles.searchDropdown}` containing `Link` elements.
- Produces: E2E test that correctly finds and clicks search results.

- [ ] **Step 1: Identify actual SearchBox DOM structure**

SearchBox renders:
```tsx
{isDropdownOpen && debouncedQuery.length >= 3 && (
  <div className={styles.searchDropdown} ref={dropdownRef}>
    {isLoading && <div className={styles.searchDropdownItem}>Loading...</div>}
    {!isLoading && results?.length === 0 && (
      <div className={styles.searchDropdownItem}>No results found</div>
    )}
    {results?.map((game) => (
      <Link key={game.gameID} href={`/game/${game.gameID}`} className={styles.searchDropdownItem}>
        {game.external}
      </Link>
    ))}
  </div>
)}
```

Correct selector: `div.searchDropdown` or find via `Link[href^="/game/"]` inside the dropdown.

- [ ] **Step 2: Fix the E2E test selectors**

Replace:
```typescript
await expect(
  page.locator('[role="listbox"], [data-testid="search-results"]').first()
).toBeVisible({ timeout: 10000 });
```

With:
```typescript
// SearchBox renders div.searchDropdown with Link children
await expect(
  page.locator('a[href^="/game/"]').first()
).toBeVisible({ timeout: 10000 });
```

And replace:
```typescript
const firstResult = page
  .locator('[role="listbox"] a, [data-testid="search-results"] a')
  .first();
```

With:
```typescript
const firstResult = page.locator('a[href^="/game/"]').first();
```
